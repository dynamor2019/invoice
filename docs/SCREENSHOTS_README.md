# 用户手册截图说明

本文档说明如何为用户手册添加功能截图。

## 截图目录结构

所有截图应放在 `docs/screenshots/` 目录下。

```
docs/
├── 用户手册.md
├── screenshots/
│   ├── login.png                    # 图1：系统登录页面
│   ├── procurement-projects.png     # 图2：采购经理/造价经理项目管理界面
│   ├── project-dashboard.png        # 图3：项目统计看板
│   ├── materials-list.png           # 图4：材料清单界面
│   ├── add-material.png             # 图5：添加材料对话框
│   ├── contracts-list.png           # 图6：采购合同界面
│   ├── add-contract.png             # 图7：新建采购合同对话框
│   ├── new-bill.png                 # 图8：新建票据界面
│   ├── bills-list.png               # 图9：票据列表界面
│   ├── user-management.png          # 图10：用户管理界面
│   └── add-user.png                 # 图11：添加用户对话框
```

## 截图要求

### 图片格式和大小
- **格式**：PNG 或 JPG
- **推荐宽度**：800-1200px
- **推荐高度**：600-900px
- **文件大小**：不超过 500KB

### 截图内容

#### 图1：系统登录页面 (login.png)
- 显示登录表单
- 包含用户ID输入框、密码输入框、登录按钮
- 显示系统标题"天津华能票据审核系统"

#### 图2：采购经理/造价经理项目管理界面 (procurement-projects.png)
- 显示项目选择下拉框
- 显示三个标签页：项目介绍、材料清单、采购合同
- 显示项目详细信息卡片

#### 图3：项目统计看板 (project-dashboard.png)
- 显示四个统计卡片（项目总数、项目总额、剩余金额、进行中）
- 显示项目状态分布图
- 显示预算使用情况

#### 图4：材料清单界面 (materials-list.png)
- 显示材料清单表格
- 包含材料名称、规格、单位、数量、单价、总价等列
- 显示"添加材料"按钮

#### 图5：添加材料对话框 (add-material.png)
- 显示模态对话框
- 包含材料名称输入框（显示自动完成建议）
- 包含其他材料信息输入字段
- 显示"保存"和"取消"按钮

#### 图6：采购合同界面 (contracts-list.png)
- 显示采购合同列表
- 显示合同卡片（包含合同名称、状态、合同号、供应商、金额等）
- 显示"新建合同"按钮

#### 图7：新建采购合同对话框 (add-contract.png)
- 显示模态对话框
- 包含合同信息输入字段
- 显示"保存"和"取消"按钮

#### 图8：新建票据界面 (new-bill.png)
- 显示票据表单
- 包含标题、金额、分类、日期等字段
- 显示图片上传区域

#### 图9：票据列表界面 (bills-list.png)
- 显示用户提交的票据列表
- 显示票据状态（待审批、已审批、已拒绝等）
- 显示票据基本信息

#### 图10：用户管理界面 (user-management.png)
- 显示用户列表表格
- 包含用户ID、用户名、角色等列
- 显示"增加用户"、"保存所有修改"等按钮

#### 图11：添加用户对话框 (add-user.png)
- 显示模态对话框
- 包含用户ID、用户名、密码输入框
- 包含角色选择（显示所有13个角色）
- 显示"确定"和"取消"按钮

## 添加截图步骤

1. 创建 `docs/screenshots/` 目录（如果不存在）
2. 使用浏览器开发者工具或截图工具截取相应的界面
3. 将截图保存为对应的文件名
4. 确保文件格式为 PNG 或 JPG
5. 将文件放在 `docs/screenshots/` 目录下

## 截图建议

- 使用清晰的截图，确保文字可读
- 隐藏敏感信息（如真实用户数据）
- 使用示例数据进行演示
- 保持截图风格一致
- 可以使用箭头或高亮标注重要功能

## 验证

添加截图后，可以在 Markdown 预览器中查看用户手册，确保所有图片都能正确显示。
