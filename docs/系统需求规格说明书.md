## 2. 系统概述

### 2.1 系统定义
天津华能票据审核系统是一套企业级的票据审批和项目管理平台，支持多级审批流程、项目材料管理、采购合同管理等功能。系统采用移动端优先设计，支持在手机、平板和电脑上使用。

### 2.2 系统目标
- 规范企业票据审批流程，提高审批效率
- 实现多级审批管理，确保财务合规
- 支持项目和材料清单管理
- 提供完整的审批历史和数据追溯
- 支持移动端访问，提升用户体验

### 2.3 主要功能模块
1. **用户认证与权限管理** - 登录、密码管理、角色权限控制
2. **项目管理** - 项目创建、编辑、查看、删除
3. **材料清单管理** - 材料、施工清单、调试清单的管理
4. **采购合同管理** - 供应商合同的创建和管理
5. **票据管理** - 票据提交、修改、查看
6. **审批流程** - 多级审批、拒绝、重提
7. **归档管理** - 已完成票据的归档
8. **系统管理** - 用户管理、审批流程配置、事由分类管理

## 4. 功能需求

### 4.1 用户认证与权限管理

#### 4.1.1 登录功能
- **需求**：用户通过用户ID和密码登录系统
- **输入**：用户ID、密码
- **输出**：JWT令牌、用户信息（ID、姓名、角色）
- **验证**：
  - 用户ID和密码必填
  - 密码验证失败返回错误提示
  - 登录成功返回7天有效期的JWT令牌

#### 4.1.2 密码管理
- **修改密码**：用户可修改自己的密码，需验证原密码
- **重置密码**：管理员可重置任意用户密码为默认值 `123456`
- **默认密码**：
  - 管理员：`admin123`
  - 其他用户：`123456`

#### 4.1.3 权限控制
- **基于角色的访问控制（RBAC）**：根据用户角色限制功能访问
- **API级权限**：所有需要权限的API需验证JWT令牌和用户角色
- **页面级权限**：前端根据用户角色显示/隐藏相应功能

### 4.2 项目管理

#### 4.2.1 项目创建
- **权限**：采购经理、造价经理、项目经理
- **必填字段**：
  - 项目名称
  - 甲方单位
  - 合同金额
- **可选字段**：
  - 项目编号（自动生成：HN-年-月-日-序号）
  - 合同编号
  - 结算金额
  - 项目状态（草稿/待审批/已审批/进行中/已完成/暂停）
  - 开始时间、结束时间
  - 工程概况、项目描述
  - 付款方式、开票信息
  - 甲方合同文件、其他项目材料

#### 4.2.2 项目编辑
- **权限**：项目创建者、采购经理、造价经理
- **功能**：修改项目信息、上传/删除附件

#### 4.2.3 项目查看
- **采购经理/造价经理视图**：
  - 项目下拉选择框
  - 三个标签页：项目介绍、材料清单、采购合同
- **项目经理视图**：项目列表展示
- **董事长/副董事长/总经理视图**：
  - 项目统计看板
  - 项目总数、项目总额、剩余金额、进行中项目数
  - 项目状态分布图
  - 预算使用情况

#### 4.2.4 项目删除
- **权限**：项目创建者、采购经理、造价经理
- **级联删除**：删除项目时同时删除相关材料清单和采购合同

### 4.3 材料清单管理

#### 4.3.1 材料添加
- **权限**：采购经理、造价经理、项目经理
- **必填字段**：
  - 材料名称
  - 数量
  - 单价
- **可选字段**：
  - 规格型号
  - 单位
  - 供应商
  - 类型（材料清单/施工清单/调试清单）
  - 备注
- **自动计算**：总价 = 数量 × 单价
- **自动完成**：输入材料名称时显示建议，点击建议自动填充规格、单位、单价

#### 4.3.2 材料编辑
- **行内编辑**：点击编辑按钮后该行变为可编辑状态
- **保存/取消**：确认修改或放弃修改

#### 4.3.3 材料删除
- **权限**：材料创建者、采购经理、造价经理
- **确认删除**：删除前需用户确认

#### 4.3.4 材料分类
- 材料清单
- 施工清单
- 调试清单

### 4.4 采购合同管理

#### 4.4.1 合同创建
- **权限**：采购经理、造价经理
- **必填字段**：
  - 合同名称
  - 供应商名称
- **可选字段**：
  - 合同编号
  - 合同金额
  - 联系人、联系电话
  - 付款方式
  - 合同文件

#### 4.4.2 合同编辑
- **权限**：合同创建者、采购经理、造价经理
- **功能**：修改合同信息、上传/删除合同文件

#### 4.4.3 合同删除
- **权限**：合同创建者、采购经理、造价经理
- **确认删除**：删除前需用户确认

### 4.5 票据管理

#### 4.5.1 票据提交
- **权限**：普通员工
- **必填字段**：
  - 票据标题
  - 金额
  - 事由分类（一级分类 > 二级项目）
  - 日期
- **可选字段**：
  - 关联项目
  - 票据图片（最多5张，单张最大10MB）
- **支持格式**：JPG、JPEG、PNG、WEBP
- **自动审批流程**：根据事由分类和金额自动确定审批路径

#### 4.5.2 票据修改
- **权限**：票据创建者（仅当被一级审批人拒绝时）
- **功能**：修改票据信息并重新提交
- **状态变更**：从"已拒绝"变为"待审批"

#### 4.5.3 票据查看
- **个人视图**：查看自己提交的票据
- **审批人视图**：查看待审批的票据
- **管理员视图**：查看所有票据

#### 4.5.4 票据详情
- 基本信息（标题、金额、分类、日期）
- 票据图片
- 审批历史
- 当前审批状态

### 4.6 审批流程

#### 4.6.1 审批路径
- **工程款项**（事由分类包含"工程"）：
  - 总经理 → 董事长
- **后勤花费**（事由分类包含"后勤"）：
  - 副董事长 → 董事长
- **其他类票据**：
  - 一级审核 → 二级审核 → 三级审核 → 董事长

#### 4.6.2 审批操作
- **通过**：票据进入下一审批环节
- **拒绝**：填写拒绝原因，票据状态变为"已拒绝"或退回上一级
- **权限**：只有当前步骤的审批人或管理员可操作

#### 4.6.3 审批免审
- **阈值设置**：管理员可为各级审批人设置免审金额阈值
- **自动跳过**：票据金额低于阈值时自动跳过该级审批

#### 4.6.4 审批历史
- 记录所有审批操作（创建、通过、拒绝、修改）
- 包含操作人、操作时间、拒绝原因等信息

### 4.7 归档管理

#### 4.7.1 归档操作
- **权限**：财务经理、会计
- **功能**：将已完成审批的票据标记为已归档
- **状态变更**：从"已审批"变为"已归档"

#### 4.7.2 归档查询
- **权限**：财务经理、会计
- **功能**：查看已归档票据列表，支持按日期、金额等筛选

### 4.8 系统管理

#### 4.8.1 用户管理
- **权限**：管理员
- **功能**：
  - 添加新用户（指定ID、姓名、密码、角色）
  - 编辑用户信息（修改姓名、角色）
  - 重置用户密码
  - 删除用户
  - 批量保存修改

#### 4.8.2 审批流程配置
- **权限**：管理员
- **功能**：
  - 设置审批顺序
  - 设置各级审批免审阈值

#### 4.8.3 事由分类管理
- **权限**：管理员
- **功能**：
  - 管理一级分类
  - 管理二级项目
  - 调整分类顺序
  - 启用/禁用分类

#### 4.8.4 公司名称设置
- **权限**：管理员
- **功能**：修改系统显示的公司名称

## 5. 非功能需求

### 5.1 性能需求
- **响应时间**：API响应时间 < 2秒
- **并发用户**：支持至少100个并发用户
- **数据库**：SQLite，支持至少10万条票据记录

### 5.2 安全需求
- **身份认证**：JWT令牌认证，7天有效期
- **密码安全**：密码以明文存储（开发版本），生产环境应加密
- **CORS**：支持跨域请求配置
- **API权限**：所有修改操作需验证用户权限

### 5.3 可用性需求
- **系统可用性**：99%以上
- **数据备份**：定期备份数据库
- **错误处理**：友好的错误提示

### 5.4 兼容性需求
- **浏览器**：支持Chrome、Safari、Firefox等现代浏览器
- **移动端**：支持iOS、Android系统
- **微信内置浏览器**：支持微信内打开

### 5.5 可维护性需求
- **代码规范**：遵循ESLint规范
- **日志记录**：记录关键操作日志
- **文档完整**：提供用户手册和API文档

## 7. API 接口规范

### 7.1 认证接口

#### POST /api/login
登录接口
- **请求**：`{ id: string, password: string }`
- **响应**：`{ id, name, role, token }`

#### POST /api/user/change-password
修改密码
- **权限**：本人或管理员
- **请求**：`{ id, oldPassword, newPassword }`
- **响应**：`{ ok: true }`

#### POST /api/user/reset-password
重置密码（管理员）
- **权限**：管理员
- **请求**：`{ id }`
- **响应**：`{ ok: true }`

### 7.2 用户接口

#### GET /api/users
获取所有用户
- **响应**：`[{ id, name, role }, ...]`

#### POST /api/users
添加用户
- **权限**：管理员
- **请求**：`{ id, name, role, password }`
- **响应**：`{ success: true, message: string }`

#### PUT /api/users/:id
更新用户
- **权限**：管理员
- **请求**：`{ name?, role?, password? }`
- **响应**：`{ success: true, message: string }`

### 7.3 项目接口

#### GET /api/projects
获取所有项目
- **响应**：`[{ id, code, name, client, totalBudget, ... }, ...]`

#### POST /api/projects
创建项目
- **权限**：采购经理、造价经理、项目经理
- **请求**：`{ name, client, contractNo, totalBudget, ... }`
- **响应**：`{ id, code, name, ... }`

#### PUT /api/projects/:id
更新项目
- **权限**：项目创建者、采购经理、造价经理
- **请求**：`{ name?, client?, totalBudget?, ... }`
- **响应**：`{ ok: true }`

#### DELETE /api/projects/:id
删除项目
- **权限**：项目创建者、采购经理、造价经理
- **响应**：`{ ok: true }`

### 7.4 票据接口

#### GET /api/bills
获取所有票据
- **响应**：`[{ id, title, amount, category, status, ... }, ...]`

#### GET /api/todos/:role
获取待审批票据
- **参数**：role - 审批人角色
- **响应**：`[{ id, title, amount, ... }, ...]`

#### POST /api/bill
创建票据
- **权限**：普通员工
- **请求**：`{ title, amount, category, date, projectId?, images? }`
- **响应**：`{ id, title, amount, ... }`

#### GET /api/bill/:id
获取票据详情
- **响应**：`{ id, title, amount, category, history, ... }`

#### POST /api/bill/approve
审批票据
- **权限**：审批人
- **请求**：`{ id, action: 'approve'|'reject', reason? }`
- **响应**：`{ ok: true }`

## 8. 部署与运维

### 8.1 部署方式

#### 开发环境
```bash
npm install
npm run dev          # 前端开发服务器
npm run server       # 后端服务器
```

#### 生产环境
```bash
npm install
npm run build        # 构建前端
npm run server       # 启动后端服务器
```

### 8.2 环境变量
- `JWT_SECRET`：JWT签名密钥（默认：dev-secret）
- `ALLOW_ORIGINS`：允许的CORS源（逗号分隔）
- `ALLOW_DEV_RESET`：是否启用开发重置接口（默认：1）

### 8.3 数据库备份
- 数据库位置：`server/data/app.db`
- 备份文件：`server/data/app.db.backup`
- 建议定期备份数据库文件

### 8.4 文件上传
- 上传目录：`server/data/uploads`
- 支持的文件类型：图片（JPG、PNG、WEBP等）
- 最大文件大小：10MB
