## 1. 系统概述

天津华能票据审核系统是一套专为企业设计的票据审批和项目管理系统，支持多级审批流程、项目材料管理、采购合同管理等功能。系统采用移动端优先设计，支持在手机、平板和电脑上使用。

### 1.1 主要功能

- **项目管理**：创建、编辑、查看项目信息
- **材料清单**：管理项目所需材料、施工清单、调试清单
- **采购合同**：管理供应商采购合同
- **票据审批**：多级审批流程，支持审批、拒绝、重提
- **归档管理**：已完成票据的归档查询
- **用户管理**：用户账户、角色、权限管理

### 1.2 系统访问

- 通过浏览器访问系统地址
- 支持微信内置浏览器访问
- 建议使用Chrome、Safari等现代浏览器

### 1.3 截图说明

本手册包含多个功能截图，帮助用户更好地理解系统操作。所有截图文件应放在 `docs/screenshots/` 目录下。如果截图文件不存在，请根据实际系统界面添加相应的截图文件。

## 2. 用户角色与权限

系统支持以下用户角色：

| 角色 | 角色标识 | 主要权限 |
|------|----------|----------|
| 管理员 | admin | 系统配置、用户管理、审批流程设置 |
| 董事长 | chairman | 项目看板、高级审批、项目审批 |
| 副董事长 | vice_chairman | 项目看板、后勤类审批 |
| 总经理 | gm | 项目看板、工程类审批 |
| 采购经理 | procurement_manager | 项目管理、材料清单、采购合同 |
| 造价经理 | cost_manager | 项目管理、材料清单、采购合同 |
| 项目经理 | project_manager | 项目查看、材料清单管理 |
| 一级审核 | approver1 | 票据一级审批 |
| 二级审核 | approver2 | 票据二级审批 |
| 三级审核 | approver3 | 票据三级审批 |
| 普通员工 | staff | 提交票据、查看自己的票据 |
| 财务经理 | finance_manager | 票据审批、票据归档 |
| 会计 | accountant | 票据归档、财务审核 |

### 2.1 角色功能说明

**管理员 (admin)**
- 管理所有用户账户
- 配置审批流程顺序
- 设置审批免审阈值
- 管理票据事由分类
- 设置公司名称

**董事长/副董事长/总经理**
- 查看项目统计看板
- 查看项目总数、总额、剩余金额
- 查看项目状态分布
- 查看预算使用情况
- 审批相关票据

**采购经理**
- 管理项目信息
- 管理材料清单（材料清单、施工清单、调试清单）
- 管理采购合同
- 查看项目详细信息

**造价经理**
- 管理项目信息
- 管理材料清单（材料清单、施工清单、调试清单）
- 管理采购合同
- 查看项目详细信息

**项目经理**
- 查看项目列表
- 管理项目材料清单
- 创建和编辑项目

**审批人员 (approver1/2/3)**
- 审批待处理票据
- 查看审批历史
- 拒绝不合规票据

**财务经理 (finance_manager)**
- 审批待处理票据
- 查看审批历史
- 拒绝不合规票据
- 查看已审批票据
- 归档已完成票据

**普通员工 (staff)**
- 提交新票据
- 查看自己提交的票据状态
- 修改被拒绝的票据并重新提交

**会计 (accountant)**
- 查看已审批票据
- 归档已完成票据
- 查看归档记录

2. 填写项目信息：

3. 材料按类型分组显示：

*图4：材料清单界面*

2. 在弹出的模态对话框中填写材料信息：
   - **材料名称** *（必填）- 支持自动完成建议
   - **规格型号** - 选择建议后自动填充
   - **单位** - 选择建议后自动填充
   - **数量**

   - **总价** - 根据数量和单价自动计算

- 提高数据输入效率

3. 点击"保存"完成添加

1. 在材料列表中找到目标材料
2. 点击删除按钮（红色垃圾桶图标）

   - **待审批**：等待审批人处理

1. 在票据列表中点击目标票据

   - 审批历史

1. 找到被拒绝的票据
2. 点击"修改并重新提交"
3. 修改票据信息
4. 点击"提交"

**注意**：只有被一级审批人拒绝的票据才能重新提交。

## 8. 审批流程

### 8.1 审批流程说明

系统支持多级审批流程，根据票据事由分类自动确定审批路径：

**工程款项**（事由分类包含"工程"）：
总经理（李长春）→ 董事长（李总）

**后勤花费**（事由分类包含"后勤"）：
副董事长（孙总）→ 董事长（李总）

**其他类票据**：
一级审核 → 二级审核 → 三级审核 → 董事长（李总）

### 8.2 审批操作

**审批人操作**：
1. 登录系统
2. 在首页查看待审批票据
3. 点击票据查看详情
4. 选择操作：
   - **通过**：票据进入下一审批环节
   - **拒绝**：填写拒绝原因

**拒绝处理**：
- 第一级审批拒绝：票据状态变为"已拒绝"，发起人可修改后重新提交
- 其他级别拒绝：票据退回上一级审批人

### 8.3 查看审批历史

在票据详情页面可以查看完整的审批历史，包括：
- 创建时间和创建人
- 各级审批人的操作时间
- 拒绝原因（如有）
- 修改记录（如有）

## 11. 常见问题

### Q1: 忘记密码怎么办？
联系管理员重置密码，重置后默认密码为 `123456`。

### Q2: 票据被拒绝后如何处理？
- 如果是一级审批拒绝，可以修改票据内容后重新提交
- 如果是其他级别拒绝，票据会退回上一级审批人

### Q3: 如何查看票据的审批进度？
在票据详情页面可以查看当前审批状态和完整的审批历史。

### Q4: 上传的图片有什么要求？
- 支持格式：JPG、JPEG、PNG、WEBP
- 单张图片最大：10MB
- 每张票据最多上传5张图片

### Q5: 项目编号和合同编号的格式是什么？
- 项目编号：HN-年-月-日-序号（如：HN-2025-01-16-001）
- 合同编号：HN-HT-年-月-日-序号（如：HN-HT-2025-01-16-001）

### Q6: 如何联系技术支持？
请联系系统管理员获取技术支持。
