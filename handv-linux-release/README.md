# Handv Linux 部署指南

本文件夹包含了在 Linux 服务器上部署所需的所有文件。

## 目录结构
- `server/`: 后端代码
- `build_tmp/`: 前端构建文件（由后端自动提供服务）
- `deploy.sh`: **一键启动脚本**
- `package.json`: 依赖配置

## 快速开始

1. **上传文件**
   将 `handv-linux-release.zip` 上传到服务器并解压。

2. **一键启动**
   进入目录并运行部署脚本：
   ```bash
   cd handv-linux-release
   chmod +x deploy.sh
   ./deploy.sh
   ```
   
   **脚本会自动执行以下操作：**
   - **清理环境**：停止并删除旧的 PM2 服务，释放 3001 端口。
   - **安装依赖**：自动安装生产环境依赖。
   - **启动服务**：使用 PM2 启动后端服务（端口 3001）。

3. **访问应用**
   服务启动后，后端会自动托管前端页面。
   - **直接访问**：`http://<服务器IP>:3001`
   - **如果使用 Nginx**：请将所有流量代理到 `3001` 端口。

## 常见问题
- **数据库**：默认包含当前的 `server/data/app.db`。如需重置，请删除该文件，系统会自动创建新库。
- **端口冲突**：脚本会强制杀掉占用 3001 端口的进程，请确保该端口未被重要服务占用。
